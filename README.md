映真 专业版 - 使用说明
====================

一、运行要求
1. Windows 10 或 Windows 11 64位系统。
2. 将压缩包完整解压后再运行，不要直接在压缩包内双击。
3. 建议解压到纯英文路径，例如 D:\YingZhen_Pro。
4. 视频处理需要较大的临时磁盘空间，请至少预留视频文件大小的5倍空间。
5. 激活与每次处理前需要联网访问授权服务器。

二、软件激活
1. 双击 YingZhen_Pro.exe（或安装包内主程序）。
2. 点击“复制机器码”，把32位机器码发送给管理员。
3. 管理员根据你的机器码签发注册码后，将注册码粘贴到软件顶部输入框。
4. 点击“激活”（需联网）。激活成功后“开始处理”按钮会启用。
5. 注册码与当前电脑机器码绑定，换电脑后需要使用新机器码重新申请。
6. 每次点击“开始处理”时会再次在线鉴权；断网或注册码被吊销时无法处理。

三、视频处理
1. 添加源视频（支持批量）。
2. 选择真实手机参考视频。
3. 选择输出位置。
4. 选择处理效果或按需要调整高级参数，然后点击“开始处理”。
5. 处理期间请勿关闭程序或移动程序目录。

四、常见问题
- 提示未激活：检查注册码是否完整、是否与本机机器码匹配、是否过期，以及是否已联网。
- 提示在线鉴权失败：确认网络畅通、授权服务器可用，或联系管理员确认是否已吊销。
- 编码失败：将视频编码器选择为“libx264（软件）”。
- 杀毒软件首次提示：本程序未做商业代码签名，可将整个目录加入信任后重试。
- 软件会在当前用户的 AppData 目录保存本机会话状态；不会上传您的视频文件。

五、目录说明
- YingZhen_Pro.exe：主程序
- bin：FFmpeg、FFprobe、ExifTool和画质模型等运行组件
- license_api.json（可选）：自定义授权服务器地址
- USER_README.txt：本说明

请仅处理你有合法使用权的视频内容。
